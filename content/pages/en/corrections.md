## How to report a mistake

Every lesson, country page and quiz question has a "Report a mistake" link. It opens a pre-filled issue in the site's public GitHub repository (you need a free GitHub account). When you report something, please include:

- the page address (URL),
- what is wrong, and
- if possible, an official source that shows the correct information.

You can also open an issue directly at [github.com/ManOfSarbloh/stockora-academy/issues](https://github.com/ManOfSarbloh/stockora-academy/issues).
