Cette politique décrit la façon dont le site est construit. L'exploitant doit la relire (idéalement avec un conseil juridique) avant de faire connaître le site, en particulier la partie hébergement. Cette version française est une traduction ; seule la version anglaise fait foi.

## Ce que nous ne faisons pas

- Aucun outil d'analyse ou de statistiques.
- Aucun cookie.
- Aucune publicité, aucun lien d'affiliation, aucun bouton de réseau social ni pixel de suivi.
- Aucun compte ni inscription. Nous ne vous demandons ni votre nom ni votre adresse e-mail.
- Les polices sont servies par ce site lui-même, et non par un service tiers.

## Ce qui est enregistré dans votre propre navigateur

Pour mémoriser vos réglages et votre progression, le site utilise le *stockage local* (localStorage) de votre navigateur. Ces données restent sur votre appareil ; elles ne nous sont jamais envoyées, ni à personne d'autre. Toutes les clés commencent par `stockora-`. Actuellement enregistrées :

- `stockora-theme` : si vous avez choisi le mode clair ou sombre.
- `stockora-progress` : les leçons que vous avez marquées comme terminées, et quand.
- `stockora-bookmarks` : les leçons que vous avez enregistrées.
- `stockora-quiz-scores` : votre meilleur et votre dernier score à chaque quiz.
- `stockora-quiz-stats` : pour chaque question répondue, combien de fois vous avez eu juste et quand elle revient (pour les modes révision et points faibles).
- `stockora-quiz-daily` : votre série au quiz du jour.
- `stockora-quiz-exam` : vos tentatives à l'Examen final, votre meilleur score et la date de réussite.
- `stockora-quiz-name` : le nom saisi pour votre certificat, le cas échéant.
- `stockora-founder-game` : si vous avez terminé le jeu du fondateur de la page « Naissance d'une action », et quand.
- `stockora-times-zone` : le fuseau horaire choisi sur la page des horaires.

Cette liste sera tenue à jour. Vous pouvez tout effacer à tout moment en supprimant les données de ce site dans les réglages de votre navigateur.

## Vidéos (YouTube)

Les leçons et les pages de thèmes contiennent des vidéos pédagogiques YouTube. Une vidéo ne se charge **pas** avant que vous cliquiez dessus ; auparavant, aucune donnée (pas même une image d'aperçu) n'est demandée à YouTube. Ce n'est qu'à ce moment que votre navigateur se connecte à YouTube (via le domaine à confidentialité renforcée `youtube-nocookie.com`), et la politique de confidentialité de YouTube s'applique. Chaque vidéo propose aussi un simple lien « Regarder sur YouTube ».

## Hébergement

Ce site est hébergé sur GitHub Pages, un service de GitHub, Inc. Comme tout serveur web, l'hébergeur reçoit les données techniques nécessaires à l'affichage des pages (par exemple votre adresse IP et des informations sur votre navigateur) et peut les journaliser, par exemple pour des raisons de sécurité. Nous n'avons pas accès aux journaux de visite.

L'exploitant du site doit vérifier les conditions et la déclaration de confidentialité actuelles de GitHub pour GitHub Pages, et ajouter ici les informations requises (prestataire, finalité, base juridique, transferts de données).

## Signaler une erreur

Les liens « Signaler une erreur » ouvrent un ticket prérempli sur GitHub. Rien n'est envoyé tant que vous ne le soumettez pas là-bas, et la déclaration de confidentialité de GitHub s'applique ; un compte GitHub est nécessaire pour soumettre.
