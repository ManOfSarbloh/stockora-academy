## Comment signaler une erreur

Chaque leçon, page pays et question de quiz comporte un lien « Signaler une erreur ». Il ouvre un ticket (issue) prérempli dans le dépôt GitHub public du site (un compte GitHub gratuit est nécessaire). Lors de votre signalement, merci d'indiquer :

- l'adresse de la page (URL),
- ce qui est faux, et
- si possible, une source officielle qui donne l'information correcte.

Vous pouvez aussi ouvrir un ticket directement sur [github.com/ManOfSarbloh/stockora-academy/issues](https://github.com/ManOfSarbloh/stockora-academy/issues). Vous pouvez écrire en français.
